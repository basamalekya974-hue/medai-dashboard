# 🩺 MedAI — Healthcare Dashboard

A polished frontend experience for managing **appointments, medications, lab results, vitals, reports, and patient healthcare information** through a clean and intuitive dashboard interface.

## ✨ What I Built

MedAI is a **frontend healthcare dashboard** designed to bring commonly used patient-management features into one organized interface.

The application includes multiple interactive pages with reusable React components and a consistent healthcare-focused UI.

### 📊 Dashboard Overview

* Overview dashboard
* Appointment management
* Book appointment interface
* Medication tracking
* Lab results
* Patient vitals
* Medical reports
* Sidebar navigation
* Appointment confirmation modal
* Responsive UI

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/basamalekya974-hue/medai-dashboard.git
```

### 2. Navigate to the project

```bash
cd medai-dashboard
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL shown in your terminal.

---

## 📦 Production Build

Create a production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## 📌 Current Scope

This version focuses on the **frontend experience**.

It currently does **not** include:

* Backend API
* Real patient database
* User authentication
* Real medical records
* AI/ML diagnosis
* Production healthcare data processing

The displayed healthcare data is intended for **demonstration and portfolio purposes only**.
